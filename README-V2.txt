# QM Archive V2 — Jekyll

This version turns the one-file V1 into a real content site.

## The important part

New writing:
`_posts/YYYY-MM-DD-title.md`

New note:
`_notes/YYYY-MM-DD-title.md`

New photograph:
`_photos/YYYY-MM-DD-title.md`

GitHub Pages builds these automatically.

## iPad workflow

If GitHub's upload UI does not preserve folders, create each file directly in GitHub with **Add file → Create new file** and type the full path, for example:

`_posts/2026-09-25-troi-mua-ha-noi.md`

The website will create the article page automatically after GitHub Pages rebuilds.
